APIs

1. Sign In API
    arguments:
        - email
        - password
    response:
        {
            "token":"sdfsd",
            "user_id": "12"
            "user_email": "abc@gmail.com"
        }

2. Sign Up API

    Argument:
        - email
        - username / name
        - mobile number
        - date of birth
        - password
        - confirm password
    response:
    {
        "success"
    }

3. Forgot Password API and mail:
    Argument:
        - email

6. Cart API:

    - list
        Argument:
            - user_id
        response:
            [{
                "cart_id": 34,
                "product_title": "sdfsd",
                "product_image_url": "dfsdf.jpg",
                "order_quantity": 4,
                "item_price": 23.00,
                "total_price": 45.00 // item_price * quantity
            }]

    - put / patch
        to change the order_quantity and total price

        Argument:
            - user_id
            - cart_id
        response:
            {
                "cart_id": 34,
                "product_title": "sdfsd",
                "product_image_url": "dfsdf.jpg",
                "order_quantity": 4,
                "item_price": 23.00,
                "total_price": 45.00 // item_price * quantity
            }

    - delete
        Argument:
            - user_id
            - cart_id
